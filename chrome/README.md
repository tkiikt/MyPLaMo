# MyPLaMo ページ翻訳

Windows版MyPLaMo 1.1.0以降のオプション機能です。Built with PLaMo

1. MyPLaMoを起動し、「モデルと設定」でダウンロード済みの翻訳モデルを選びます。
2. 本体画面上部の「Chromeからの翻訳を受け付ける」をオンにします。本体は通知領域にしまっても使えます。
3. Chromeの chrome://extensions でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」でこのZIPの中の extension フォルダーを選びます。
4. 翻訳したいWebページで右クリックし、「MyPLaMoでWEB全体を翻訳」を選びます。拡張アイコンからも開始できます。本文やリンク、後から追加された文章も順番に日本語になります。右下の「原文に戻す」か拡張アイコンで原文に戻せます。

本体のモデル・GPU・文体設定を使います。本体と拡張からの依頼は同じエンジンで順に処理します。翻訳先は日本語です。PDFや画像内の文字、埋め込みフレーム、コードや入力欄は対象外です。

旧版から更新する場合は、専用の連携アプリを通知領域から終了し、本体を更新してください。前と同じ場所に拡張を展開した場合はChromeの拡張機能管理画面で再読み込みしてください。モデルを切り替える場合は本体の「モデルと設定」を使います。
