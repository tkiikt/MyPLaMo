# 用語集バックアップ・復元の検証（2026-11-13）

## 実装

- 用語集画面の「バックアップ」で保存済みの全用語集を `.myplamo-glossary` に保存する。
- ファイルは識別ヘッダー、展開後JSONのSHA-256、GZip圧縮したバージョン付きJSONで構成する。用語集名・ID・原語・訳語・翻訳方向・並び順・空の用語集を保持する。
- 「復元」でファイルを選び、追加件数・用語数・スキップ件数・用語集名を確認してから追加する。現在の用語集は上書きしない。
- 名前と用語が一致する既存の用語集を1件ずつ対応させてスキップする。バックアップ内に意図的に同名・同内容の用語集が複数あっても、その件数を維持する。
- IDが衝突して内容が異なる場合は新IDで追加する。既存の翻訳用語集の選択は保持する。
- ファイル破損・非対応バージョン・不正な用語・件数超過は保存前に拒否する。復元の保存失敗時はメモリー上の変更も戻す。
- バックアップの書き込みは同じフォルダーの一時ファイルに完了させてから置換する。読み込みは圧縮前後とも128MiBを上限とする。
